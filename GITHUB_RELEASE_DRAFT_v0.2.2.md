# Project Synapse v0.2.2

Project Synapse is a public research prototype for **resource-conditioned hypernetwork adaptation**.

This `v0.2.2` patch release does not change model behavior or reported experiment results. It improves the repository's academic presentation after the public launch by making authorship, citation metadata, and licensing details explicit and easier to reuse.

## Highlights

- Named author metadata in `CITATION.cff`
- Repository links included in citation metadata
- Explicit authorship file in `AUTHORS.md`
- Cleaned MIT license ownership and formatting

## Why This Matters

This release makes the project easier to:

- cite in research writing,
- reuse as a public software artifact,
- review as a professional academic code release.

## Scope

- No architecture changes
- No behavior changes
- No benchmark changes

The verified experiment paths and public results from `v0.2.1` remain unchanged.
