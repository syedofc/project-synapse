# Code of Conduct

Project Synapse is released as a public research artifact. We want the repository to be a respectful, constructive place for discussion, critique, and collaboration.

## Our Standard

Participants in this project are expected to:

1. communicate respectfully and professionally,
2. critique ideas and implementations without attacking people,
3. acknowledge uncertainty and limitations honestly,
4. support an environment that is welcoming to researchers, students, and practitioners from different backgrounds.

## Unacceptable Behavior

The following behavior is not acceptable:

1. harassment, intimidation, or personal attacks,
2. discriminatory or demeaning language,
3. bad-faith misrepresentation of another person's work or intent,
4. public or private abuse that makes collaboration unsafe.

## Scope

This code of conduct applies to repository issues, pull requests, discussions, and other project communication channels that may be added in the future.

## Reporting

If you encounter behavior that violates this code of conduct, report it through the repository maintainer contact or the platform reporting tools available where the interaction occurred.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, or contributions that do not align with this code of conduct.
