# Security Policy

Project Synapse is research software and is not intended for security-critical or production deployment in its current form.

## Reporting a Vulnerability

If you believe you have found a security issue, please avoid posting exploit details publicly in an issue. Instead, contact the maintainer privately through the repository contact details once the project is published.

## Scope

Because this repository is a research artifact, security response times and support guarantees may be limited. Vulnerabilities that affect bundled example code, scripts, or development dependencies are still worth reporting.

## Current Status

This project should be treated as:

1. research software,
2. not hardened for production,
3. unsuitable for handling sensitive workloads without additional review.
